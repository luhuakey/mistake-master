# 《学霸省题》开发运行说明

## 1. 安装与启动

```bash
npm run install:all
cp server/.env.example server/.env
npm run dev
```

开发环境默认使用内存数据库，以及阿里云读光 OCR、DeepSeek、百炼 Embedding 和 DashVector 的本地替身，不需要云密钥即可调试页面和接口。服务重启后内存数据会清空。

注意：`MOCK_EXTERNAL_SERVICES=true` 时，识别页展示的是固定数学示例，不会与上传图片内容一致。页面会显示“当前为演示识别”。如需验证真实 OCR 与 AI 解析，请在 `server/.env` 中本地填写密钥并设置：

```text
MOCK_EXTERNAL_SERVICES=false
ALIBABA_CLOUD_ACCESS_KEY_ID=<RAM AccessKey ID>
ALIBABA_CLOUD_ACCESS_KEY_SECRET=<RAM AccessKey Secret>
ALIYUN_OCR_ENDPOINT=ocr-api.cn-hangzhou.aliyuncs.com
ALIYUN_OCR_REGION_ID=cn-hangzhou
ALIYUN_OCR_SINGLE_ACTION=RecognizeEduQuestionOcr
ALIYUN_OCR_PAPER_CUT_ENABLED=true
ALIYUN_OCR_PAPER_CUT_ACTION=RecognizeEduPaperCut
ALIYUN_OCR_PAPER_ACTION=RecognizeEduPaperOcr
ALIYUN_OCR_IMAGE_TYPE=photo
ALIYUN_OCR_SUBJECT=default
ALIYUN_OCR_NEED_ROTATE=true
# 使用独立 DeepSeek 服务时填写以下两项；配置完整时优先使用
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_MAX_TOKENS=8192
# 不使用独立 DeepSeek 时，结构化解析与 Embedding 共用百炼兼容模式配置
DASHSCOPE_BASE_URL=https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
DASHSCOPE_API_KEY=
AI_REQUEST_TIMEOUT_MS=90000
RECOGNITION_TASK_TIMEOUT_MS=240000
```

密钥只应保存在本地或部署平台的服务端环境变量中，不要写入小程序代码或提交到代码仓库。

## 2. 微信开发者工具

1. 使用微信开发者工具打开项目根目录。
2. 确认 AppID 为 `wx7d9c6a2740751b9d`。
3. 执行“工具 → 构建 npm”，生成 `miniprogram/miniprogram_npm`。
4. 开发版、体验版和正式版默认都通过 `wx.cloud.callContainer` 的微信云开发私有链路访问云托管，不依赖微信公众平台的 `request` 合法域名。请确认小程序 AppID `wx7d9c6a2740751b9d` 已关联云开发环境 `development-d3g6c1hqv2750bedf`，且环境中的云托管服务名为 `mistake-master-server`。
5. 需要联调本机服务时，先在项目根目录运行 `npm run dev`，再在开发者工具调试器 Console 执行 `wx.setStorageSync('__mistake_master_use_local_api__', true)` 并重新编译。本地链路只在 `envVersion=develop`、运行平台为 `devtools` 且显式开关为 `true` 时生效。
6. 本地联调完成后执行 `wx.removeStorageSync('__mistake_master_use_local_api__')` 并重新编译，即可恢复云托管。真机、体验版、正式版、审核环境，以及无法读取环境信息的异常场景都会保持云托管链路，不会访问 `localhost`。

开发者工具本地联调时，仓库的私有工具配置已关闭合法域名校验。该配置只对本地工具生效，不能作为审核或真机可访问本机服务的依据。云托管调用失败时页面会提示云环境、权限或服务发布问题，不会误报成本地服务故障。

体验版可访问云托管还必须同时满足：当前 AppID 已关联 `CLOUD_ENV_ID` 对应的环境；服务列表中的名称与 `CLOUD_SERVICE_NAME` 完全一致；目标版本处于“正常”状态且有流量（通常为 100%）。公网 `/health` 正常只说明容器在线，不能证明该小程序拥有 `callContainer` 私有链路访问权限。若云环境属于其他小程序，即使同一主体也需先配置“环境共享”，再使用资源方 AppID 和环境 ID 初始化跨环境云实例。

体验版和正式版的图片不能以 Base64 直接放入 `callContainer` 请求体，否则容易触发 `-606001` 请求包过大。当前实现会先用 `wx.cloud.uploadFile` 上传到 `client-uploads/`，随后只向服务端发送 `cloud_file_id`；服务端下载并校验图片、复制到用户正式目录后清理临时文件。开发版 HTTP 链路仍兼容 Base64。该链路同时修改了小程序和服务端，修复发布时必须重新部署云托管版本，并重新上传小程序体验版。

头像文件体积较小，云端上传额外提供受限兜底：个人中心通过 `wx.chooseImage` 复用拍照识别已经声明的相册/相机选择能力，避免调用未在小程序隐私保护指引中声明的 `chooseAvatar`，也避免开发者工具初始化 `chooseMedia` 内部 WASM 时重复产生窗口信息监听；选中后通过 Canvas 2D 居中缩放为 160×160 JPEG，并上传至用户隔离的 `users/{用户ID}/profile-staging/` 临时目录。若小程序端仍因云存储安全规则或环境权限无法写入，前端会继续按 320×320、240×240 或 160×160 尝试压缩，并在请求体低于云托管限制时直接提交给服务端，由服务端写入正式头像目录。普通试题图片不会使用该兜底，仍需保证云存储客户端上传权限正常。云存储失败会使用 `CLOUD_STORAGE_*` 错误码，不再误报为云托管服务连接失败。

本地头像副本必须在云端上传结束后再保存。文件系统 `saveFile` 会接管 Canvas 生成的临时文件，如果与 `wx.cloud.uploadFile` 并发执行，上传任务可能在读取前遇到 `createUploadTask:fail file not found`。当前实现已改为串行执行，并使用 `wx.getFileSystemManager().saveFile` 替代已废弃的 `wx.saveFile`；保存新副本后会清理旧副本，避免长期占用本地文件配额。

用户名称编辑使用普通 `input type="text"`，由用户手动输入后保存。不要改成 `type="nickname"`，否则基础库会调用微信昵称快捷填写组件 `showNicknameAccessory`；在小程序隐私保护指引未声明对应信息范围时，运行态会返回 `errno:112`。

正式头像文件采用 `users/{用户ID}/profile/avatar-{唯一版本}.{扩展名}` 路径，而不是重复覆盖固定的 `avatar.jpg`。数据库切换至新文件成功后再清理旧头像，确保微信图片组件和 CDN 每次获取不同 URL，避免页面提示保存成功却仍显示旧缓存。包含此修复的服务构建标识为 `2026-08-30-versioned-avatar-v8`。

业务 JWT 统一使用 `X-App-Authorization` 传递；服务端同时兼容标准 `Authorization` 头。

识别链路分为“创建任务、OCR、AI 结构化解析”三个可恢复阶段：创建任务会快速返回，随后小程序按任务状态驱动 OCR 和 AI 解析，不依赖响应返回后的后台任务。某一阶段连接中断时会先查询已落库进度，再从未完成阶段继续；如果服务端 OCR 或 DeepSeek 超时，识别任务会落为 `failed` 并显示可重试原因，不会无限转圈。

CloudBase JS SDK 的文档更新响应在部分网关版本中可能只返回 `requestId`，不返回 `updated` 计数。数据层此时会回读记录并逐字段确认补丁已经落库；首次回读不一致时，使用已读取的完整记录加补丁执行 `set` 兜底写入并二次回读，仍不一致才返回 `CLOUDBASE_UPDATE_UNCONFIRMED`。健康检查响应中的 `build` 可用于确认云端是否已换到包含该修复的新镜像。

AI 返回的科目支持中英文标准值及常见别名（例如“数学”会归一化为 `math`）。模型返回空科目、`science` 等非标准值时，服务端会结合题干、选项、解析和知识点自动推断，不再因为科目字段格式问题让整题失败；推断存在多个合理学科时保留候选科目，由用户在识别结果页最终归类。

保存入库的标准题型均可加入练习：单选、多选、判断、填空和计算题由服务端自动判分；简答、证明、阅读、作文和其他主观题在结果页展示参考答案，由用户选择“基本正确”或“需要复习”后计入掌握度。

## 3. 正式环境配置

复制 `server/.env.example` 并填写：

- CloudBase 环境 ID。
- CloudBase 服务端 API Key（推荐），或可用于服务端签名的腾讯云密钥。
- 微信小程序 Secret。
- 阿里云 RAM AccessKey（仅授予调用 OCR 所需权限）。
- 独立 DeepSeek API Key 和 Base URL（可选）；未配置时自动复用百炼兼容模式的 Host 和 API Key。
- 阿里云 DashVector Serverless（深圳）Endpoint、API Key 与 Collection。
- 阿里云百炼业务空间 API Host 与 API Key，用于 `text-embedding-v4`。
- PDF 中文字体路径。

AccessKey 配置完成后，还必须在同一阿里云账号中开通“文字识别 OCR → 教育场景识别”，并为 RAM 用户授予调用权限；仅创建 AccessKey 不会自动开通服务。单题调用 `RecognizeEduQuestionOcr`。批量识别会并行调用 `RecognizeEduPaperCut` 和 `RecognizeEduPaperOcr`：前者保留题目边界和 LaTeX 公式，后者校对容易漏掉的负号、根号与指数，并在切题结果缺少连续编号题目时补回漏题。无题号口算网格会合并 OCR 碎片，按每个算式生成一道题并由服务端逐式计算。切题接口未开通或未返回结构时使用整页结果回退。正式部署前应同时开通“题目识别”“试卷切题识别”和“整页试卷识别”，并保证三个接口均有可用额度。

同时设置：

```text
NODE_ENV=production
DATA_DRIVER=cloudbase
MOCK_EXTERNAL_SERVICES=false
```

## 4. Docker/云托管镜像

`server/Dockerfile` 使用 `node:22-bookworm-slim`，构建时安装 `fonts-noto-cjk`，并设置：

```text
PDF_FONT_PATH=/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
PDF_FONT_FAMILY=NotoSansCJKsc-Regular
```

因此正式镜像中的 PDF 会明确选用 Noto CJK 字体集合里的简体中文字体族；字体加载失败时接口会返回明确错误，不再退回 Helvetica 生成乱码。`server/.dockerignore` 会排除本地依赖、密钥文件和测试文件，缩小构建上下文。可在项目根目录验证镜像：

```bash
docker build -t mistake-master-api ./server
docker run --rm -p 8080:8080 --env-file server/.env mistake-master-api
```

云托管发布时不会读取被 `.dockerignore` 排除的本地 `server/.env`，必须在云托管版本的“环境变量”中单独配置第 3 节列出的变量。其中登录的必需项为：

```text
NODE_ENV=production
DATA_DRIVER=cloudbase
MOCK_EXTERNAL_SERVICES=false
APP_SESSION_SECRET=<随机强密钥>
CLOUDBASE_ENV_ID=<云开发环境 ID>
WECHAT_APP_SECRET=<当前小程序 AppSecret>
```

发布新版本后，提审前必须验证公网健康检查：

```bash
curl --fail --max-time 10 https://mistake-master-server-301904-11-1306434603.sh.run.tcloudbase.com/health
```

期望返回 `success: true`、`status: ok`、`capabilities.auth: true`，且当前 `build` 为 `2026-09-01-learning-points-v3`。随后开启开发者工具的合法域名校验，再验证开发版、体验版和真机登录。

## 6. 阿里云语义检索

已确认使用 DashVector Serverless（深圳）+ 百炼 `text-embedding-v4`（1024 维）。CloudBase `questions` 仍是业务事实数据源，DashVector 只保存向量和用于隔离检索的元数据。

1. 在阿里云创建深圳地域的 DashVector Serverless 集群，获取集群 Endpoint 和 API Key。
2. 在百炼创建 API Key，并获取业务空间 ID。本项目使用兼容 OpenAI 的北京 API Host。
3. 在 `server/.env` 填写（不要把真实密钥提交到仓库）：

```env
VECTOR_PROVIDER=dashvector
DASHVECTOR_ENDPOINT=https://<集群 Endpoint>
DASHVECTOR_API_KEY=<DashVector API Key>
DASHVECTOR_COLLECTION=questions
DASHSCOPE_BASE_URL=https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
DASHSCOPE_API_KEY=<百炼 API Key>
EMBEDDING_MODEL=text-embedding-v4
EMBEDDING_DIMENSION=1024
```

4. 初始化 Collection：

```bash
cd server
npm run dashvector:init
```

脚本会创建 1024 维、`FLOAT`、`cosine` Collection，并预定义 `user_id`、`subject`、`question_type` 字段。集合已存在时可安全重复执行。

5. 全量重建 CloudBase 历史题目索引：

```bash
DATA_DRIVER=cloudbase MOCK_EXTERNAL_SERVICES=false npm run dashvector:reindex
```

重建按每批 10 道题调用 `text-embedding-v4`，再 Upsert 到 DashVector；不会删除 CloudBase 原题目。单批失败会将对应题目的 `index_status` 标记为 `failed`，可在排除配置或额度问题后重跑。

配置缺失或阿里云向量服务暂时不可用时，智能搜索会自动降级为当前用户题库内的关键词匹配，不返回 502。

### 6.1 搜索模式与页面提示

- 正常状态：服务端分别执行 DashVector 语义检索和 CloudBase 关键词检索，按题目 ID 去重后按最高相关度排序，响应 `search_mode=hybrid`。
- 瞬时异常：语义请求自动重试一次；恢复后仍按联合检索返回。
- 降级状态：配置缺失或重试后仍失败时返回关键词结果，响应 `search_mode=keyword_fallback`，并附带不包含密钥、Endpoint 或服务端详情的 `degradation_code`。
- 小程序仅在实际降级时显示黄色提示；联合检索成功时显示绿色“语义与关键词联合检索”提示。
- 低相关结果由服务端统一过滤：关键词最低 `0.45`；语义最低 `0.25`。语义首条低于 `0.45` 时，只保留与首条相差不超过 `0.08` 的候选。调整阈值时需同步更新自动化测试与产品/技术文档，不要只在小程序端隐藏卡片。

`degradation_code` 可能值：

| 值 | 含义 |
| --- | --- |
| `VECTOR_NOT_CONFIGURED` | DashVector 配置缺失 |
| `EMBEDDING_NOT_CONFIGURED` | 百炼 Embedding 配置缺失 |
| `EMBEDDING_FAILED` | 文本向量化请求失败 |
| `VECTOR_SEARCH_FAILED` | DashVector 查询失败 |
| `SEMANTIC_SEARCH_UNAVAILABLE` | 未分类的语义服务异常 |

### 6.2 历史索引修复

新保存的错题会自动生成向量；历史题目或 `index_status=failed` 的题目需要执行：

```bash
npm run dashvector:init
npm run dashvector:reindex
```

重建脚本读取 CloudBase 中的错题正文，调用百炼生成向量，再向 DashVector 写入向量、题目 ID、`user_id`、科目和题型。执行前应确认用户已知悉该处理范围。脚本不会删除或改写 CloudBase 原题；成功后题目的 `index_status` 更新为 `ready`，失败则更新为 `failed` 并可安全重跑。

成功输出示例：

```json
{"success":true,"indexed":9,"failed":0,"collection":"questions"}
```

若页面仍提示降级，依次检查：环境变量是否齐全、Collection 维度是否为 1024、百炼接口是否可用、DashVector 是否可查询，以及 CloudBase 中 `index_status` 是否仍有 `failed`。

若本地语义搜索正常、云托管提示 `VECTOR_ACCESS_DENIED`，检查 DashVector 控制台“访问控制 → 公网 IP 白名单”。未配置白名单时默认允许所有公网 IP；一旦配置，仅名单内 IP 可访问。不要长期使用 `0.0.0.0/0`。云托管如使用高级定制版自有 VPC，需要先配置 NAT 网关和固定弹性公网 IP，再只将该出口 IP 加入 DashVector 白名单。若提示 `VECTOR_COLLECTION_NOT_FOUND`，确认云托管中的 `DASHVECTOR_ENDPOINT`、`DASHVECTOR_COLLECTION`、`EMBEDDING_DIMENSION` 与本地完全一致。

## 8. 微信隐私保护指引（提审前必做）

代码中的登录页已默认不勾选协议，且提供完整《用户服务协议》《隐私政策》。发布者仍需登录微信公众平台，在“小程序设置—用户隐私保护指引”中更新并提交平台侧指引：

- 选中的照片或视频信息：用于用户主动拍摄或选择错题图片，进行 OCR 文字识别、AI 结构化解析并保存到个人错题本。
- 账号标识及学习数据：用于微信账号登录、隔离个人错题、保存练习记录和生成学习统计。
- 第三方处理服务：如实填写腾讯云 CloudBase、阿里云读光 OCR、DeepSeek、阿里云百炼与 DashVector 的用途。
- 填写与小程序实际主体一致的联系方式和数据保存期限。

平台侧隐私指引审核通过后，再重新生成体验版并依次验证：默认未勾选、两份协议可以完整滚动阅读、未勾选不能登录、主动勾选后可以登录、首次拍照或选图时隐私授权提示正常。
